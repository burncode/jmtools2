# JMTools

JMTools 是一个基于 Tauri + React + TypeScript 的游戏资产生成流水线工具。

目标是把素材生成、动画制作、地图素材生成、图集制作、音乐和音效制作串成一个面向游戏开发的闭环工作台。

初期架构规划见：[docs/initial-concept.md](docs/initial-concept.md)
